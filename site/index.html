Install

Pick your browser. It takes under a minute.

Firefox 140 or newer

  1. Click Add to Firefox.
  2. If Firefox says it blocked the request, click Continue to installation.
  3. Click Add in the prompt that follows.

The add-on is signed by Mozilla, so it stays installed after restarting Firefox.

Chrome, Edge, Brave developer mode

  1. Download the .zip and unzip it to a folder you'll keep.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.

Chrome only installs store extensions directly, so this one loads as an unpacked extension.

How the numbers work

The extension uses the Pythagorean letter chart.

Letters
A–I count as 1–9, then the count starts over: J = 1, K = 2 … S = 1 … Z = 8. Upper and lower case are the same.
Digits
Count as themselves, so 2025 is 2 + 0 + 2 + 5 = 9.
Everything else
Spaces, punctuation and accented letters are skipped.
Raw
The plain sum of all values.
Reduced
The digits of the sum are added together until one digit is left, except for the master numbers 11, 22 and 33, which are kept as they are.
