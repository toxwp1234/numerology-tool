Pythagorean

The system most modern numerologists use, named after the Greek mathematician. The alphabet is written out in rows of nine, so each letter takes the number of its column.

  • Letters are worth 1 to 9: A = 1 … I = 9, then J = 1 again.
  • The total is reduced by adding its digits until one digit is left.
  • The master numbers 11, 22 and 33 are not reduced.

Chaldean

An older system traced to ancient Babylon. Letters are grouped by how they sound rather than by alphabet order, so the values look irregular.

  • Letters are worth 1 to 8. No letter is given 9, which is held sacred.
  • The compound number, the total before reducing, is read for its own meaning.
  • It is then reduced to a single digit like the Pythagorean total.

In both systems

  • Upper and lower case count the same.
  • Digits count as themselves, so 2025 adds 2 + 0 + 2 + 5.
  • Spaces, punctuation and accented letters are skipped.
